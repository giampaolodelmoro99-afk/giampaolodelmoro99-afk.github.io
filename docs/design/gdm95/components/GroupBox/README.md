Riquadro con titolo: raggruppa controlli correlati con una linea incisa e una legenda in grassetto.

## Cosa fornisce chi lo usa
- `legend`: nome breve del gruppo.
- `children`: i controlli.

## Note
È un `fieldset` con `legend`, quindi gli screen reader annunciano il gruppo. La linea è un bordo `--color-shadow` di 1 px con luce `--color-highlight` sotto; in alto contrasto diventa bianca.
