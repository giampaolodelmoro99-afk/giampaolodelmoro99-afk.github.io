Barra di stato in fondo alla finestra, fatta di campi incassati con `--bevel-status`.

## Cosa fornisce chi lo usa
- `fields`: `[{ text, grow? }]`; un solo campo con `grow` occupa lo spazio libero.
- `label` per il nome del gruppo.

## Note
Testi brevi, troncati con l'ellissi. Se un testo cambia e va annunciato (esito di un invio), annuncialo con una regione `aria-live="polite"` separata.
