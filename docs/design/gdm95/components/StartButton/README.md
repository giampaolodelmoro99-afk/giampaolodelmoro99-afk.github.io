Pulsante Start con il monogramma originale GDM in pixel art e la scritta "Start"; apre il menu Start.

## Cosa fornisce chi lo usa
- `children`: le voci `MenuItem` (con `icon`) e `MenuSeparator` del menu Start.

## Regole
- Usa solo il monogramma GDM (`icon="gdm"`), mai loghi o bandierine di terzi.
- Menu aperto: il pulsante resta premuto (`aria-expanded="true"`).
- La fascia verticale del menu porta "gianpaolodelmoro" su `--color-accent`; è decorativa (`aria-hidden`).
